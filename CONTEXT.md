### Judul final (dari isian Google Form pengguna)

- **ID:** Analisis Sensitivitas Produk Elevasi Global terhadap Pemetaan Kerawanan Banjir Berbasis Machine Learning Menggunakan Google Earth Engine: Studi Komparatif SRTM, Copernicus DEM GLO-30, dan ALOS AW3D30 di Wilayah Pesisir Semarang-Demak

### Inti penelitian (5 kata)

**DEM → RF → MAP → COMPARE → STRATIFY**

Desain: AOI, flood inventory Sentinel-1 (satu kejadian), prediktor non-topografi, sampling + seed, split data, dan parameter RF **dikunci identik**;
**hanya SUMBER produk elevasi yang diubah** (SRTM, Copernicus GLO-30, ALOS AW3D30).
Framing = sensitivitas sumber (bukan resolusi — ketiganya ~30 m).
Output: 3 peta probabilitas + perbandingan metrik (accuracy/precision/recall/F1/ROC-AUC) + analisis sensitivitas spasial (Δprobabilitas, kesesuaian, perubahan kelas) + stratifikasi kelas WorldCover + rekomendasi DEM.

**Yang sengaja TIDAK ada** (keputusan pengguna via isian form): multi-event, DEMNAS, NASADEM, SHAP, uji statistik Friedman/Wilcoxon.

## 2. Strategi & Aturan Main

1. **Satu dokumen dua fungsi**: tulis proposal agar strukturnya bisa langsung dikonversi ke artikel IMRAD.
2. **Tidak bergantung pada data request**: desain 100% GEE-native (`gorelick2017`); seluruh analisis raster + RF (`ee.Classifier.smileRandomForest`) di GEE.
3. **Proteksi ide**: `git init` folder ini + push repo privat GitHub; konsultasi dosen sebelum UTS agar topik tercatat resmi.
4. **Kerahasiaan desain**: ke anggota kelompok statling cukup sebut "topik pemodelan banjir berbasis data spasial". Detail desain tidak dibahas.
5. **Etika penulis**: paper sem-4 (6 penulis) — kontribusi metopen harus jelas berada DI ATAS naskah itu; sitasi naskah baseline (`hakim2026`, DOI `10.15294/smds.v1i1.62500`); tidak ada daur ulang teks dan tidak ada pengulangan ML+SHAP.
6. **Klaim jujur**: tanpa kata "pertama/belum pernah ada" sebelum systematic review; Sentinel-1 = flood inventory (bukan ground truth); SRTM ≈ DEM C-band; Copernicus/ALOS = DSM (bukan bare-earth DTM).
7. **Hindari risiko jilid-2 vs Verdyansyah dkk. 2025 (ML+SHAP+S1 Demak)**: desain baru memang tanpa SHAP dan memakai eksperimen sensitivitas DEM terkontrol — kontribusi = propagasi perbedaan sumber DEM ke keputusan kelas + sensitivitas spasial, bukan model ML baru.
