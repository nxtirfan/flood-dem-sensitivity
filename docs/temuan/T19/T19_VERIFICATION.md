### 2.2 Bukti Matematis Grid Historis `stratifiedSample` vs Grid `label_native_projection_control`

Pemeriksaan numerik terhadap seluruh `5.956` koordinat titik sampel di [`training_sample_features.csv`](https://drive.google.com/file/d/1gPDTueGRDzkIxChW2sbzgmI1tqnEX2yC/view?usp=drivesdk) (skrip `T19/derive_historic_grid.py`) membuktikan secara pasti bagaimana Google Earth Engine mengevaluasi `label_for_sampling.stratifiedSample(scale=30, geometries=True)` pada saat run historis:

1. Selisih minimum antarkoordinat unik pada ke-`5.956` titik adalah `min_dlon = 0,000269494585197°` dan `min_dlat = 0,000269494585225°`.  
2. Nilai tersebut sama persis dengan konstanta konversi skala meter-ke-derajat Earth Engine pada `EPSG:4326`: \$\$\\Delta\\theta \= \\frac{30\\text{ m}}{111.319,49079327357\\text{ m/derajat}} \= 0,00026949458523585647^{\\circ}\$\$  
3. Ketika ke-`5.956` koordinat dibagi dengan \$\\Delta\\theta\$, seluruh koordinat jatuh tepat pada pusat piksel setengah-bilangan bulat \$(i \+ 0,5)\\Delta\\theta\$ dan \$(j \+ 0,5)\\Delta\\theta\$ dengan residu maksimum `3,49 × 10⁻¹⁰` (bujur) dan `1,05 × 10⁻¹⁰` (lintang).  
4. Mengapa grid `stratifiedSample` memakai `0,000269494585236°` dan bukan grid native SRTM `1/3600 = 0,000277777777778°`? Karena di Earth Engine, `flood_raw = s1_ratio.gt(...).And(after_pol_db.lt(...)).And(permanent_water.Not()).And(slope_for_label.lt(5))` adalah operasi biner berantai yang mewarisi proyeksi band pertama (`s1_ratio`), yaitu hasil `ImageCollection.median()` dari Sentinel-1 yang memiliki proyeksi komposit default `EPSG:4326` dengan transformasi identitas `[1, 0, 0, 0, 1, 0]`. Saat `stratifiedSample(..., scale=30)` dipanggil pada `label_for_sampling`, Earth Engine mengevaluasi graph `flood_label` pada grid `EPSG:4326` beresolusi `0,000269494585236°` (`30,000000 m`), **bukan** pada grid native SRTM (`0,000277777777778°`, `30,922081 m`) dan **bukan** pada grid `EPSG:32749` (`30 m`).  
5. Akibatnya, pusat piksel pada `label_native_projection_control` berjarak `0,734 m` s.d. `19,747 m` dari koordinat titik sampel historis, sedangkan pusat piksel pada `EPSG:32749` berjarak `5,524 m` s.d. `20,447 m` dari koordinat titik sampel historis.
